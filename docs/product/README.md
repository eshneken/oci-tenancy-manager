# Product

[OCI Tenancy Manager specification](oci-tenancy-manager-spec.md) records scope and acceptance
criteria. [Current reference guides](../reference/README.md) distinguish implemented local behavior
from approved future design and real-provider qualification.

The specification includes accepting onboarding while keeping an employee in the normal directory
without provisioning; this differs from a no-tenancy exemption.

Shared tenancy membership can also start directly from the tenancy's Current members section.
