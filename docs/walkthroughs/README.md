# Static walkthroughs

[Open the walkthrough index](index.html) for illustrative application flows. Serve this directory
with a loopback static server as described in the index. These assets describe their declared
design subset; they are not a second running application or proof of live OCI behavior.

The [UI baseline](../../DESIGN.md) and [screen authority](../ui-screen-authority.md) distinguish
current React behavior, preserved design contracts and deferred capabilities. Superseded visual
experiments and raw comparison captures remain private history.
