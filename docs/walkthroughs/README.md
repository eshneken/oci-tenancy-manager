# Static walkthroughs

[Open the walkthrough index](index.html) for illustrative application flows. To view it over
HTTP, run `python3 -m http.server 8000 --bind 127.0.0.1 --directory docs/walkthroughs` from the
repository root. The walkthroughs illustrate their declared design scope using sample data.

The [UI baseline](../../DESIGN.md) and [screen authority](../ui-screen-authority.md) distinguish
current React behavior, preserved design contracts and deferred capabilities. Superseded visual
experiments and raw comparison captures remain private history.
