Administrator checklist

  1. Open the OCI activation email, finish password and MFA setup, then sign in to the requested child. Name and home region were already submitted. Oracle activation guide.
  2. In the child profile menu, open Tenancy and copy its OCID; open the activation administrator's User settings and copy that user's OCID. A work-request ID is not the tenancy OCID. Find OCI IDs.
  3. Open Identity & Security → Domains → Default → Users → Create user. Use the bootstrap username below, not email-as-username; complete contact fields, assign Administrators and copy the new user OCID. Create administrator.
  4. In the domain's Administrators page (or Security → Administrators), add the bootstrap user to Identity domain administrator. Domain roles and OCI group membership are separate. Assign domain role.
  5. On the bootstrap user's API keys page, choose Add API Key → Paste a public key and register only the app-provided public PEM. Do not generate another key pair. Upload public key.
  6. Return the tenancy, bootstrap-user and activation-user OCIDs. Keep temporary access until OTM verifies replacement access and previews cleanup. Never enter passwords, OTPs or private keys here. These are sample screens; no usable key is issued.
